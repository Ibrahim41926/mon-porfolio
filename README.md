## Stack

Next.js 16 (export statique), React 19, TypeScript, Tailwind CSS 4, déployé sur GitHub Pages.

## Lancer en local

```bash
npm install
npm run dev     # http://localhost:3000/mon-porfolio
npm run build   # génère le site statique dans out/
```

Les projets se modifient dans `app/components/Projects.tsx`, les images sont dans `public/`.
